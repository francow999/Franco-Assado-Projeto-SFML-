# Projeto de Faculdade - Franco Assado
Este é um projeto de um jogo 2D desenvolvido com o objetivo de demonstrar algumas estruturas
de dados. Mais especificamente, como as pilhas, filas e estruturas não-lineares funcionam. Inspirado em jogos de flash, principalmente Pappa's Burgueria. Ele foi desenvolvido utilizando o SFML na versão 2.6.1! Fique atento para instalar versões posteriores, pois o projeto pode não rodar!

## Como o Jogo Funciona?
É simples: Sempre terá alguns clientes aparecendo, e você deve atendê-los memorizando a comanda. Após o cliente terminar de fazer o pedido, você monta o lanche e entrega para ele, pontuando um score. Caso erre, você automaticamente perde!
